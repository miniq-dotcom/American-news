# US SI Financial Intelligence

**美国金融与政策情报分析平台**

一个基于 Python 和 AI 的自动化情报分析平台，旨在从美国政府、官方机构及可靠信息源获取一手金融数据与政治新闻，通过多个 AI 模型进行总结、分析与比较，并将结果可视化展示在网页上。

## 项目简介

本项目使用 Python 编写数据采集与处理程序，从各类官方信息源获取实时或定期更新的数据。

通过接入不同 AI 模型的 API，对采集到的新闻和金融数据进行翻译、总结、分类与分析。

使用 SQLite 保存原始数据及 AI 分析结果，通过 FastAPI 提供后端接口，结合 Nginx 实现网站服务与公网访问，最终将数据可视化展示在网页上。

## 核心功能

- **一手数据采集：** 获取美国政府、官方机构及可靠来源发布的原始信息。
- **自动更新：** 定期检查消息源，发现新内容后自动采集。
- **数据处理：** 新闻提取、清洗、分类与去重。
- **AI 分析：** 自动翻译、总结新闻并分析政策背景及潜在市场影响。
- **多模型比较：** 接入多个 AI 模型，比较不同模型的分析结果。
- **历史数据管理：** 保存原始新闻和分析记录，支持历史检索。
- **数据可视化：** 通过网页展示新闻、金融数据和 AI 分析结果。

| 网页解析 | BeautifulSoup、Trafilatura |

| 后端框架 | FastAPI |

| Web 服务器 | Nginx |

| 版本管理 | Git、GitHub |

3. 数据库存储模块
4. AI 分析模块
5. FastAPI 后端模块
